# Bivvy for Windows

Bivvy is a desktop schedule and task companion for Windows 10/11 (x64).

[Download the latest Windows installer](https://github.com/fr-anz/Bivvy-releases/releases/latest/download/Bivvy-Setup.exe)

This repository contains public installers and update metadata. Application source is kept separately.

Install Bivvy for your Windows user account. Installed versions check for updates automatically; open Settings → General to check manually or install an available update and restart.

Releases include `Bivvy-Setup.exe`, its update signature, and `latest.json`. Bivvy verifies signatures before installing updates. Windows publisher signing (Authenticode) is not configured yet.
